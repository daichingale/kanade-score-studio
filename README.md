# Kanade 継続開発版

Kanade v0.2 Finale風入力版を、このフォルダーで継続的に編集する開発環境です。
今後はZIPを作り直さず、`app/web/` の同じファイルを更新します。

## Windowsで開く

1. このフォルダーの **「Kanadeを開く.bat」** をダブルクリック。
2. ブラウザで **http://127.0.0.1:5173** が開きます。
3. 起動した黒いウィンドウは開いたままにしてください。終了するにはそのウィンドウで Ctrl+C を押します。

このPCではインストール済みのWindows版Node.js 22.16.0を使用します。
別のPCではNode.js 20以降が必要です。npm installや外部サービスへの接続は不要です。
二度起動した場合は、既に動いている同じプロジェクトを開きます。
5173番ポートを別のアプリが使っている場合は停止してから再実行してください。
保存場所が変わるのを防ぐため、自動で別ポートには切り替えません。

## 編集と自動反映

- `app/web/src/app.js`：入力・選択・キーボード操作
- `app/web/src/core.js`：楽譜データと編集規則
- `app/web/src/renderer.js`：五線・音符・半透明カーソル
- `app/web/fonts/Bravura.woff2`：同梱記譜フォント。ライセンスは `app/web/fonts/LICENSE-Bravura.txt`
- `app/web/src/musicxml.js`：書き出し
- `app/web/index.html` / `style.css`：画面と見た目

譜面記号にはBravuraを埋め込み、オフラインでも同じ字形です。
CSSは保存後にページを開き直さず差し替えます。
JavaScript・HTMLは保存後に自動再読み込みし、楽譜、選択位置、音価、入力モード、Undo/Redo履歴、譜面のスクロール位置を戻します。
文字入力欄を編集中の場合は、入力欄から離れてから反映します。再生音は再読み込み時に停止します。
開発サーバー停止中も表示中の楽譜を編集できます。再起動すると再接続・反映します。
`scripts/` の変更時は開発サーバーを再起動してください。

手動で開発する場合は、このフォルダーで `npm run dev`、テストは `npm test`。
Node.jsを直接使う場合は `node scripts/dev.mjs --open`、`node scripts/test.mjs` です。
Windowsでは **「テストを実行.bat」** も使えます。

## 吹奏楽AIに相談する（ローカルの Ollama）

メニューの **相談**、または Ctrl+J で、吹奏楽・マーチングの相談パネルを開けます。
編成、音域、移調、リハーサル、ドリルなど、楽譜を見ながらの質問に答えます。
開いている楽譜からは曲名・パート・小節数・テンポ・調だけを読み、音符の追加や削除はしません。
会話はこのブラウザに保存されます。**履歴を消去** で消せます。
譜面の編集、保存、オフライン利用はこれまでどおりです。Ollama が止まっているときは、パネルに起動方法を表示します。

モデルの取得には [Ollama](https://ollama.com/download) を使います。開発サーバーが `127.0.0.1:11434` へ中継するので、ブラウザ側の CORS 設定は不要です。

### Windows

1. Ollama をインストールし、スタートメニューから起動する。
2. PowerShell またはコマンドプロンプトでモデルを取得する。

```bat
ollama pull qwen2.5:7b
```

メモリが少ない PC では `ollama pull qwen2.5:3b` でも相談できます。

3. **Kanadeを開く.bat** または `npm run dev` で http://127.0.0.1:5173 を開く。
4. **相談** を押し、一覧の Qwen を選んで質問を送る。

### Linux

```bash
ollama serve
ollama pull qwen2.5:7b
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開き、**相談**（Ctrl+J）からチャットを使います。

## 以前作った楽譜の引き継ぎ

旧ZIP版の画面で **保存** し、`.kanade.json` をこの画面の **開く** から読み込んでください。
旧版の `file://` と開発版の `http://127.0.0.1:5173` はブラウザの自動保存領域が別です。
新しい画面で楽譜が空でも旧画面のデータを削除したわけではありません。

通常の再読み込みでは楽譜を自動保存から戻しますが、Undo履歴の引き継ぎは開発サーバーによる自動反映時のみです。
自動保存はブラウザ内です。残したい楽譜は **保存** でファイルにも保存してください。

## Finale風の操作

半透明の音符カーソル、←/→で音符・休符間移動、↑/↓で音高変更をv0.2から継承しています。
数字キー：1=64分、2=32分、3=16分、4=8分、5=4分、6=2分、7=全音符。

Backspace/Deleteは選択音符を消した後、同じ小節内の前の音符を選択します。連打すると前へ順に削除します。未入力部分や休符からは直前の音符が対象です。削除した位置は休符として残り、後続の拍位置を保ちます。
詳しくは [Finale風操作ガイド](Finale風操作ガイド.md) を参照してください。
単一譜表・単一声部の試作版です。拍子に沿う連桁に対応しました。Rustエンジン統合、複数パート、連符等は未対応です。

## スコア範囲編集（2026-11-02）

- Shift+←/→またはShift+クリックで音符・休符の範囲を選択。小節をまたいで選べます。Ctrl+Aは楽譜全体、上部の「小節選択」は現在の小節全体です。
- 範囲選択中の↑/↓、Shift+↑/↓、＋/－は全選択音符をまとめて移調します。R、L、音価・付点の操作にも対応しています。
- Ctrl+C/X/V、または上部のボタンでコピー・切り取り・貼り付け。コピー内容はこのKanade画面内で保持し、別の楽譜を開いて貼り付けることもできます。
- 貼り付けは範囲の先頭またはカーソル位置から、コピーした長さだけを置き換えます。範囲外の音符・拍位置を保持し、末尾では必要な小節を追加します。コピー元の音高・歌詞・符幹設定も保持し、IDは新しく発行します。
- 音符を小節線で分割するタイは未対応のため、そのような貼り付けや、範囲外の音符の途中を切る貼り付けは変更せず止めます。
- 範囲選択中のDelete/Backspaceは音符を休符に置換し、小節自体と後続の拍を保ちます。通常の単音選択では従来の連続削除です。
- 下部の「手前に挿入」「小節複製」「小節削除」で、選択範囲がまたがる小節をまとめて編集します。小節削除は音符を含む小節全体を削除し、全部を削除した場合は編集用の空小節を1つ残します。
- 1回の編集は1回のUndoで戻せます。Escまたは通常の左右移動・クリックで範囲選択を解除します。文字入力欄ではCtrl+A/C/X/Vを通常どおり使えます。
- 選択範囲・カーソルは印刷/PDFに出しません。SVG書き出しも選択表示を除いた譜面です。

モデルの回帰テストは `app/web/tests/score-editing.test.js`、操作テストは `tests/score-editing.browser.cjs` です。複数パート・複数声部の編集は引き続き未対応です。

## マーチングパーカッション音源（2026-11-02）

（初回追加時の操作。現在は下記の共通「再生音源」に統合済み。）左側のアイコン付き「スネア / テナー / バス / シンバル」で、楽譜全体の内蔵音源を切り替えます。「楽器」欄からも選べます。各打面パッドを押すと、選択中の音価で入力して確認音が鳴ります。Space／再生でも同じ音源を使い、保存・再読み込みで楽器を保持します。

- スネア：C=センター、D=リムショット、E=スティック。
- テナー：C〜G=ロー、ミッドロー、ミッド、ハイ、スポック。
- バス：C〜G=バス5（低）〜バス1（高）。
- シンバル：C=ハイハット・オン（閉）、D=ハイハット・オフ（開）、E=クラッシュ、F=チョーク。オンは直前の開いたハイハットを、チョークはシンバルの余韻を止めます。

パッドはC4〜G4の通常の音符として入力します。打楽器の再生では音名だけを打面に対応させ、オクターブと臨時記号は無視します。対応のない音名は各音源の先頭の打面です。音源を切り替えると既存音符も新しい対応で再生します。楽譜そのものの音高や調号は書き換えません。

軽量なWeb Audio合成音源です。実録サンプル、外部SoundFont/VSTの読み込み、ベロシティ、多段階サンプル、ロール／フラム等の奏法、打楽器専用譜表・MusicXMLの打楽器マップは未対応です。SVGとMusicXMLは従来の音高表記で出力します。通常楽器は従来の簡易音源です。音源・アイコンとも外部ダウンロード不要です。

保存・開く・コピー・切り取り・貼り付け・小節編集には、文字ラベルと並べてアイコンを常時表示します。打楽器の選択アイコンもメニューを開かず利用できます。

## 音部記号・譜線・移調・再生音源（2026-11-02 更新）

- 上部の「音部記号」でト音・ヘ音・ハ音（アルト／テナー）・ニュートラル（打楽器）を選択。「譜線」は1〜5本に対応します。
- スネア等の1線譜は「ニュートラル＋1線譜＋通常符頭」、シンバルなら「ニュートラル＋1線譜＋×符頭」を選びます。1線打楽器では音名を変えても符頭は同じ線上に並び、打面の区別は元の音名で保持します。マウス入力は直前に選んだ音名を使います。
- 「記譜音 → 実音」はC管、B♭管、A管、F管、E♭管、低音のB♭／E♭管、オクターブ上下。例えばB♭管で記譜C4を入力すると実音B♭3で鳴ります。音符と調号は記譜音で入力します。この設定を変えても音符や調号を自動で書き換えません。ニュートラルでは調号と移調を適用しません。
- 左の「再生音源」で、現在の譜面を鳴らす音色を共通のリストから選択します。音源の変更は音符・音部記号・譜線・移調・パート名を変えません。パート名は別欄で編集できます。旧データは既存の楽器名を初期音源に使います。
- 打楽器だけの常設選択セクションを廃止。打面パッドは対応音源を選んだときの「打面の対応・入力」を開いたときだけ表示します。ハイハット閉／開・クラッシュ・チョークは引き続き使えます。
- 「音色を試聴」は選択音符、未選択時はC4を鳴らします。移調も反映します。

ピアノ、トロンボーン、トランペット、フルート、クラリネット、ヴァイオリン、ホルン、アルト／テナーサックス、チューバ、オーボエ、ファゴットはFluidR3 GMのサンプル音源に変更しました。ユーフォニアムはチューバ音源で代用し、画面に明記します。その他は簡易シンセ、マーチング打楽器は内蔵合成音源です。サンプルは同梱し、使用中の外部通信や追加インストールは不要。近いサンプルをリサンプリングし、持続楽器はループします。強弱別サンプルや奏法切替・VST/SF2読み込みは未対応です。

MusicXMLにもハ音・打楽器記号、譜線数、移調、無音高音符、×符頭、再生プログラムを書き出します。打楽器の外部再生はGMの近い音へ割り当てるため、内蔵音と同じ音色・チョーク効果を保証しません。SVG／印刷は画面と同じ譜表を使います。KSLは実験用で、これらの追加設定はまだ出力しません。

音源の出典と加工内容は [同梱音源の表示](app/web/samples/ATTRIBUTION.md)。FluidR3のMP3配布元は [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts/blob/gh-pages/README.md)、ライセンスは [CC BY 3.0 US](https://creativecommons.org/licenses/by/3.0/us/)。記譜と書き出しは [MusicXMLの打楽器仕様](https://www.w3.org/2021/06/musicxml40/tutorial/percussion/) と [移調仕様](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/transpose/) に基づきます。

## 譜面を中心にした画面配置（2026-11-02）

通常画面は左の音符パレットと、入力／選択・拍子・調号・テンポ・再生をまとめた1段のツールバーです。右側の詳細欄は初期状態では閉じています。コピーや小節操作の常設行、長い説明文、音源選択を譜面の周囲から移しました。

- **ファイル**：新規・開く・サンプル譜・書き出し。保存と操作検索は右上にも常時表示。
- **編集**：小節選択・コピー／切り取り／貼り付け・小節追加／挿入／複製／削除。既存のキーボード操作も使えます。
- **楽譜**：音部記号・譜線数・移調・符頭・パート名・作曲者。
- **再生**：共通の再生音源・試聴・打面の対応。楽譜を見ながら設定できる小さなパネルで開きます。
- **表示**：音符の詳細・操作ガイド・アプリ情報。音符の詳細は曲名の右のボタンからも開閉できます。

設定パネルは×、Esc、譜面などパネルの外をクリックすると閉じます。音名・オクターブのボタンは左パレットの同名の項目を開くと使えます。プロパティを開いた状態だけ譜面の右側に詳細欄を表示します。印刷とSVGにはメニューや設定パネルを含めません。楽譜データ、保存キー、音源、Finale風のキー操作は従来と同じです。

## ピンチ・移動・拡大縮小（2026-11-02）

- **タッチ画面**：2本指で開く／閉じると譜面を拡大／縮小。2本指を同じ方向へ動かすと移動できます。1本指はタップで音符入力／選択、ドラッグで譜面移動。移動やピンチでは音符を入力しません。
- **タッチパッド**：ピンチで譜面を拡大／縮小、2本指スクロールで移動できます。ブラウザーがCtrl＋ホイールとして通知するピンチに対応しています。
- **マウス**：譜面上のCtrl＋ホイールで拡大／縮小。通常ホイールは縦スクロール、Shift＋ホイールは横スクロール。中央ボタンのドラッグ、またはHで選ぶ手のひらツールでも移動できます。
- **表示倍率**：右下の−／＋、倍率の数字（100%へ戻す）、「幅」を使います。表示メニューにも同じ操作があります。25〜300%に対応。
- **キー操作**：Ctrl＋＋／Ctrl＋−で拡大／縮小、Ctrl＋0で100%、Hで手のひらツール切替、Escで手のひらツール解除。文字入力中はこれらのキーを譜面操作として奪いません。

ピンチは2本指の中心、Ctrl＋ホイールはマウス位置を中心に拡大します。「幅に合わせる」はウィンドウや詳細欄の開閉にも追従します。表示倍率はこのブラウザーに保存し、楽譜ファイルやUndo履歴とは分けて保持します。開発時の自動反映では倍率と移動位置を引き継ぎます。印刷・SVG・MusicXMLへ表示倍率を持ち込まず、音符の入力位置も拡大後の五線に従います。

## インターネット共同編集・アプリ版（2026-11-04）

Web版のURL： https://kanade-score-studio.versionthree.chatgpt.site/index.html

1. ローカル版またはWeb版の上部 **共同編集** を開き、表示名を入力。
2. **この楽譜のルームを作る** を押して **リンクをコピー**。
3. 友だちに招待リンクを送り、友だちはリンクをブラウザーで開きます。ローカル版の **リンクから参加** に貼り付けても参加できます。

招待リンクを知る人が編集できます。一般のアプリURLだけでは共有楽譜を閲覧できません。招待キーはURLの#以降に保持し、APIではAuthorizationヘッダーを使います。作成者は **招待リンクを更新** で以前のリンクを無効化でき、**ルームを終了** もできます。更新後は友だちへ新しいリンクを送り直してください。

異なる小節と異なる設定への変更は、通常約0.5秒ごとの同期で合流します。同じ小節を同時に編集した場合は競合として止め、自分の版を保持します。**自分の編集を保存** でファイルに残し、**共有版を読み直す** から再開してください。入力中の曲名などは確定するまで受信した変更の表示を待ちます。参加者の名前と編集している小節は共同編集パネルに表示します。

共同編集中のUndo/Redoは自分の同期済み操作が対象です。他の人が同じ箇所を変更した後は巻き戻さず、理由を表示します。通信切断中の変更はそのタブのsessionStorageに保持して再接続時に再送します。同じタブの再読み込みでも保留中の変更を復元します。タブを閉じる前や接続が戻らない場合は、ファイルへ保存してください。新規作成・別ファイル読み込みは退出後に行います。**退出して自分の楽譜に戻る** は、参加前の楽譜に戻ります。ルームの内容を個人ファイルにも残す場合は先に保存してください。

ルームは作成から30日、共有楽譜は1 MBまで、同じ接続元からの作成は1時間に10回までです。通常の個人編集と保存にはこの制限はありません。譜面はCloudflare D1に保存し、サーバー再起動や参加者のブラウザー終了後も保持します。Web版の公開はSitesを使い、ユーザーのPCを起動し続ける必要はありません。

**アプリとして使う**：Web版をEdge／Chromeで開き、ブラウザーの「アプリをインストール」を選びます。対応ブラウザーでは **表示 → アプリとしてインストール** も表示されます。タスクバー等から独立したウィンドウで起動でき、Web版と同じ招待リンク・共同編集を使えます。通常のWindows起動バッチも引き続き利用できます。

実装：`app/web/src/sync.js`（条件付き小節差分）、`collaboration.js`（招待・同期・再接続）、`server/rooms.mjs`（共通API）、`hosting/`（Sites/Vinext/D1の公開用プロジェクト）。`hosting/public` と `dist` は正本の `app/web` から生成する公開成果物で、編集対象の別コピーではありません。公開ソースのIDは `.openai/hosting.json`。移行SQLは `drizzle/` に保存します。

検証用APIサーバーはNode.js 22.13以降で `node server/dev-collab.mjs`（127.0.0.1:5174）。通常のアプリは公開URLのAPIへ接続します。ブラウザーテストだけが検証サーバーへ接続先を変更します。共同編集テストは `tests/collaboration.browser.cjs`、モデル／APIは `tests/collaboration.test.mjs`。音部記号・音源・タッチ・既存ショートカットは共通です。

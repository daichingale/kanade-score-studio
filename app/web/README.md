# Kanade Web Preview v0.2（Finale風入力）（依存関係ゼロ）

継続開発ではリポジトリ直下の `Kanadeを開く.bat` を使います。Node.js 20以降が必要です。
保存後の自動反映と開発手順は [ルートのREADME](../../README.md) を参照してください。
`index.html` の直接起動も可能ですが、自動反映はありません。

## Finale風の操作（今回の追加）
- 音価パレットまたは数字キー1–7で音価を選択。五線上に半透明の音符と「4分音符」などの音価ラベルが表示されます。
- 五線上の空き位置をクリックすると、その拍に音符を配置できます。既存音符の位置はずれません。
- ← →：音符・休符ごとのカーソル移動（未入力部分の休符も含む）。↑ ↓：選択音符の音高変更。
- 既存音符をクリックすると選択。Shift+クリックは常に選択のみ。
- N：音符配置、V：選択、Esc：選択モード。Alt + 1–7：選択した音符/休符の音価変更。
- 1=64分 / 2=32分 / 3=16分 / 4=8分 / **5=4分** / 6=2分 / 7=全音符。

## できること
- 単一譜表・単声部に音符/休符を挿入、和音追加、音高変更、歌詞入力
- 拍子（4/4, 3/4, 2/4, 6/8 など）、調号、ト音/ヘ音記号、テンポ、楽器の設定
- 拍子の長さを超える入力を防止、空き時間は表示/書出時に休符で埋める
- Undo/Redo、ローカル自動保存、プロジェクト JSON 保存/再読込
- MusicXML 4.0、SVG、試験的 KSL 出力、ブラウザの印刷→PDF、簡易 WebAudio 再生

## 制限（重要）
- **この版は Finale の操作思想を取り込んだ試作であり、Finale の完全互換ではありません。** 動作範囲と今後の実装仕様は [Finale風操作ガイド](../../Finale風操作ガイド.md) を参照してください。
- `*.kanade.json` は **Web Preview 専用**。Rust エンジンの正式な `.kanade` / `.kanade.d` 形式と互換ではありません。
- Rust で実装済みの `kanade-model`/`kanade-layout` をまだ呼び出していません。現在の描画は Web Preview 専用の簡易 SVG であり、クロススタッフ連桁・臨時記号の複雑な規則・タイ/スラー・連符・ページ組版・複数声部・移調楽器に対応しません。
- KSL は現時点で**出力のみ**。歌詞も KSL 出力には含みません。KSL の仕様への完全準拠は未検証です。
- SVG のフォント表示は環境によって異なります。正式版では SMuFL の同梱/パス化が必要です。
- MusicXML は基本的な単一パート向けの**書き出しのみ**。別ソフトへの読み込みは MuseScore 等で検証してください。
- 音源は簡易シンセサイザー。総譜、楽器別音源、ダイナミクス等の演奏解釈は未対応です。

## テスト
Node.js があれば、リポジトリ直下で `node --test app/web/tests/*.test.js`。

## 本体への統合方針
元の設計資料は今回のプレビューZIPには同梱されていません。次に Rust `Session`、WASM ブリッジ、共通表示リストを完成させ、Web Preview の暫定モデルを削除して Rust を唯一の正として使います。

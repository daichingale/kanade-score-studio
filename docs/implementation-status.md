## 2026-11-04：インターネット共同編集とインストール可能なWebアプリ

SitesのVinext/WorkersとD1を使う公開先を追加。個人編集の正本と固定URLは継続し、共通のWeb UIから招待リンクでルームを作成／参加する。Windowsのローカル版も公開APIを利用し、Web版はPWAとしてインストールできる。画面の常設要素は共同編集メニューと参加中の短い状態表示のみ。

同期は条件付きの小節・設定パッチと楽譜版番号を使う。D1のrevision条件付きUPDATEをCASとして用い、競合時は最新版へ再試行する。別小節の変更は合流し、同じ小節や小節順の競合は409で返す。クライアントは楽譜と送信待ちパッチをタブ内に退避し、相手の版で上書きしない。操作IDで応答喪失時の再送を重複適用しない。Undo/Redoは自分の差分の逆パッチを条件付き適用し、相手が変えた小節を巻き戻さない。入力中のフォームを受信版や状態更新で消さず、確定後に合流する。

招待キーと管理キーを別々に生成し、D1はハッシュだけを保存。招待キーはフラグメントから取得しAuthorizationで送る。作成者のキーだけが招待更新／終了を行える。公開APIはモデル検証、サイズ制限、作成元の回数制限、接続元チェックを行う。ルーム期限30日・楽譜1MB。参加者は表示名と小節・位置を送信し、30秒以内の参加者を表示する。同期は500ms間隔、非表示時は2500ms。常時接続WebSocketや文字単位CRDTではなく、小節単位の競合検知方式。

PWAはマニフェスト、ローカルアイコン、ネットワーク優先のサービスワーカーを追加。API、開発ルートと共有楽譜はキャッシュ対象外。個人版を退出用バックアップとして保存し、共有版は専用の送信待ち保存キーを使う。通常の楽譜ファイル形式は変更しない。ファイルを閉じる前の未送信変更は個別ファイルへの保存が必要。

## 2026-11-18：吹奏楽AIの相談パネル（Phase 1）
